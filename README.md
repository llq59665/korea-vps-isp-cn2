## 先搞懂几个绕不开的技术词：原生IP、双ISP、CN2优化

选韩国VPS之前，有几个词你一定会在各家商家的产品描述里反复看到，搞不懂这几个词，很容易被参数表唬住。

**原生IP** 指的是IP段本身就是由韩国本地运营商直接分配、注册在韩国的IP地址，跟机房用国际BGP网络随便拉一段IP去搭日本或韩国机器完全是两回事。原生IP在Netflix、TikTok这类平台的风控系统里，被识别为"本地用户"的概率明显更高。

**双ISP住宅IP**又往前走了一步。普通的原生IP虽然注册地在韩国，但本质上还是数据中心IP段，容易被平台标记为机房IP。双ISP住宅IP则是通过韩国本土的家庭宽带运营商（比如KT、SK这类）拿到的IP，风控系统看到的效果跟一台真实摆在首尔某个公寓里的电脑没有区别，这也是为什么这类IP在做TikTok运营、解锁本土流媒体时特别受欢迎。

**CN2/三网优化**说的是国内访问韩国服务器时走的线路。如果没有优化，电信、联通、移动用户访问同一台韩国服务器的速度可能天差地别,高峰期卡顿、丢包也很常见。三网优化基本上是国内用户对韩国VPS的硬性要求，不是加分项，是及格线。
